O **MPARC (Manchester Protocol Automation for Risk Classification)** é uma aplicação web desenvolvida para apoiar a implementação do **Protocolo de Manchester**, uma metodologia utilizada na triagem e classificação de risco em serviços de saúde.

O sistema permite:

- Fluxos de atendimento clínico;
- Registro e consulta de classificações;
- Associação das classificações aos fluxogramas e discriminadores clínicos;
- Visualização das classificações realizadas nos últimos dias;
- Autenticação segura de profissionais;
- Exportação semanal de dados;
- Separação entre operações administrativas e acesso dos profissionais.

A aplicação utiliza uma interface em React, uma API em Node.js/Express e banco de dados PostgreSQL, podendo ser executada com Docker.
